## fdf (42)

Projet consistant à afficher une carte filaire en 3D à partir de données de relief.

### Contenu

- Lecture et parsing de fichiers de données
- Projection isométrique
- Affichage graphique en temps réel
- Gestion des événements utilisateur

### Contexte

Projet de l’école 42 ayant pour objectif d’introduire les bases de la programmation graphique, des projections 3D et de la gestion de données en C.
